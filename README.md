# LeetTrack

力扣中国站的桌面练习记录器。自动同步每天做过的题，用题单查看练习次数，安排每天要复习的内容，也可以直接在软件里写代码。

## 下载与安装

在 [GitHub Releases](https://github.com/devinfenn/leettrack/releases/latest) 下载 `LeetTrack-Setup-0.1.1-x64.exe`。支持 Windows 10/11 的 64 位系统。

1. 双击安装包，按中文向导选择安装用户和目录。
2. 安装完成后，从桌面或开始菜单打开 **LeetTrack**。
3. 点击右上角 **连接账号**，在软件打开的力扣中国站页面登录，随后自动同步。
4. 使用题单查看练习次数，进入复习页处理今日安排，或进入编程页写代码。

安装包包含桌面运行环境，无需另外安装 Node.js。当前发行版尚未签署 Windows 代码签名，Windows 可能显示未识别发布者提示。同一 Release 提供 SHA-256 校验值。

在 Windows“设置 → 应用”中可卸载。练习记录和代码草稿保存在当前用户目录，卸载保留这些数据。

## 功能

- **自动记录**：运行时每 5 分钟同步，返回软件或电脑唤醒时检查新提交，至少间隔 30 秒。退出后停止同步，重新打开时检查新增提交。评测中的记录会较快刷新。
- **每天只计一次**：同一道题、北京时间同一天，无论提交多少次，只记一个练习日。当日任意一次通过，显示已通过；失败或待评测仍计练习，不推进复习间隔。
- **题单**：内置官方热题 100、面试经典 150，显示练过几天与最近练习日期。支持题名/题号搜索和练习状态筛选。
- **每日复习**：每天最多 6 道到期题；选择独立做出、需要提示或没做出，安排下一次。同一天修改反馈只计一次，反馈不会新增刷题记录。
- **编程**：C++ 17 编辑器，支持高亮、缩进、折叠、撤销和搜索。按题号/题名或中国站题目链接选择题目；草稿按账号和题目分别自动保存。
- **账号与备份**：连接/切换账号，连续补齐历史、暂停和续传，导出提交记录与复习反馈的 JSON 备份。

独立做出按 1、3、7、14、30、60 天逐步延长间隔；需要提示安排 2 天后，没做出安排明天并优先出现。当天新通过的题从次日开始复习。稍后复习只切换当前题，不表示完成。复习依据已同步历史和用户反馈调整，不自动推断是否真正掌握。

## 编程模式

**LeetCode 模式**只编辑核心代码。运行样例和提交力扣通过应用自己的登录会话交给力扣中国站。正式提交取得评测结果后同步原始提交；运行样例和本地检查不添加练习记录。

**ACM 模式**将核心算法和 `main` 分成两个编辑区。核心保持 LeetCode 的 `Solution` 接口，main 负责读取输入、调用核心函数、打印结果。

- **检查输入输出**：替换核心函数为测试函数，运行实际 main，比较传入参数、调用次数及打印结果。使用官方样例参数、多组输入和不同空白字符。返回值是测试预设，不执行用户算法，也不表示算法通过。
- **运行样例**：本地编译并执行实际核心代码和 main，显示 stdout/stderr，可编辑测试输入。一次本地运行不等于算法 AC。
- **提交力扣**：先检查输入输出，通过后只把当前核心代码交给力扣完整评测，不发送 main 或本地助手。

ACM 输入第一行是 `T`。每组按函数参数顺序读取；一维数组先读长度，二维数组先读行数、再逐行读长度和元素；字符串用双引号包围。每组答案换行，数组元素用空格分隔。题目左侧的输入输出约定显示具体格式。

支持普通函数题的数字、布尔、字符串、一维/二维数组，以及有输出参数元信息的原地修改题。链表、树、设计类和互动题暂不生成 ACM 接口，仍可使用 LeetCode 模式。IO 检查验证当前协议和测试，不证明所有可能的输入均正确。

网络中断或查询超时后，可在本次应用会话中继续查询已收到的评测编号，避免重复发送。请求未取得编号时，需要先在力扣站内核对是否收到提交。

### 配置 ACM 的 C++ 编译器

电脑已有 g++ 时，打开右上角设置，点击 **选择编译器**，选择安装目录中的 `g++.exe`。软件检查、保存配置并立即启用。

尚未安装时，按 [MSYS2 官方说明](https://www.msys2.org/) 安装并更新 MSYS2，在 **MSYS2 UCRT64** 终端执行：

```sh
pacman -S --needed mingw-w64-ucrt-x86_64-gcc
```

默认位置是 `C:\msys64\ucrt64\bin\g++.exe`。选择实际安装位置即可。安装包暂不包含 C++ 工具链。也支持 PATH 中的 g++ 或 `LEETTRACK_CXX` 环境变量；在设置中选择的编译器优先。

编译最多等待 30 秒，单次程序运行 2.5 秒，输出最多 128 KB。本地执行是当前用户权限的正常程序执行，不提供隔离沙箱。

快捷键：`Ctrl+Enter` 运行、`Ctrl+Shift+Enter` 提交、`Ctrl+S` 保存，编辑器内部 `Ctrl+F` 搜索；题单和记录页 `Ctrl+K` 搜索，`Esc` 清空搜索。

## 题单与同步范围

题单为 2026-10-02 的公开官方快照，位于 `src/catalog.js`：

- [LeetCode 热题 100](https://leetcode.cn/studyplan/top-100-liked/)
- [面试经典 150 题](https://leetcode.cn/studyplan/top-interview-150/)

官方题单调整后需要更新快照。提交接口未提供题目 slug 时，使用题单和公开题库元信息匹配；模糊或多义题名不自动合并，无法确认时打开提交详情。

每批最多读取 200 条原始提交；补齐历史连续读取并保存进度，可暂停和跨重启续传。离线期间新增超过一批时继续读取。练习天数和复习仅依据已同步数据，历史未补齐时标注范围。

网络失败从 30 秒起逐渐延长间隔重试，最长 15 分钟；尊重服务器限流等待时间。登录过期或验证页面提示用户处理。历史接口拒绝访问时保留数据、停止历史任务，普通新增记录仍可同步。

## 数据保存

安装版根目录：`%APPDATA%\LeetTrack\`。开发版根目录：项目的 `.local/`。二者分别保存，首次使用安装版需重新连接账号；开发版的原有数据仍保留。

| 目录/文件 | 内容 |
| --- | --- |
| `records/` | 按账号隔离的原始提交元信息与同步进度 |
| `reviews/` | 独立保存的复习反馈 |
| `coding/` | 草稿、测试输入和题目缓存 |
| `profile/` | 应用自己的登录会话 |
| `preferences.json` | 本地编译器位置 |

提交按 ID 去重、原子存盘，界面按题目和北京日期合并。文件损坏时保留原文件，网络失败时已有数据可继续查看。关闭窗口前等待当前草稿保存。

导出格式为版本 2，包含账号、时间、提交记录和复习反馈，不包含会话或代码草稿。备份代码需保留 `coding/`。不要分享个人数据目录。

登录窗口仅允许力扣中国站域名，不读取系统浏览器会话，也无需复制 Cookie。第三方 OAuth 跳转尚未验证；切换账号时，在力扣窗口先退出当前账号再登录。

源码和安装包不包含个人会话、练习数据或开发阶段的历史设计文件。

## 开发与打包

使用 Node.js 24，在项目目录执行：

```sh
npm ci
npm start
```

```sh
npm test
npm run dist:win
```

本地 C++ 测试需要 g++。`dist:win` 在 Windows 上生成中文 NSIS 安装向导，输出位于 `dist/`；`pack:win` 生成解包目录用于验证。图标由 `scripts/create-icons.ps1` 生成，许可证由 `scripts/generate-notices.cjs` 收集，编辑器本地打包。

GitHub Actions 在推送后运行测试并构建 Windows 安装包。发布包采用明确的文件白名单，构建产物和个人数据不提交到 Git。

`LeetTrack.exe --verify-installation` 检查打包后的界面、存盘和 C++ 执行。运行前必须设置 `LEETTRACK_DATA_DIR` 指向独立临时目录；该检查不连接力扣。验证结果和限制见 [VERIFICATION.md](VERIFICATION.md)。

第三方组件许可证见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
